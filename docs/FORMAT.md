# `.w11ab` 文件格式，版本 1

字节布局：7 字节魔数 `W11ABK\x01`，16 字节随机盐，12 字节随机 nonce，随后为 AES-GCM 密文及 16 字节认证标签。魔数、盐和 nonce 一起作为附加认证数据。

密码按 UTF-8 编码，以 scrypt（N=32768、r=8、p=1）派生 32 字节密钥。参数由格式版本固定，不接受文件自带的任意计算成本。新建密码要求至少 10 个字符；密码不修剪空白、不做 Unicode 归一化，读取时必须与创建时完全相同。

认证后的明文是 ZIP，包括 `manifest.json` 与零个或多个 `store/` 下的普通文件。清单包含格式名称、版本、许可快照、备注，以及每个归档文件的 SHA-256 和长度。整个清单也处于认证加密范围内。内部 ZIP 不应另行发布，因为其中含有完整产品密钥。

读取上限为 80 MiB，文件数据总量上限为 64 MiB，单文件上限为 32 MiB，清单上限为 1 MiB，文件数量上限为 512。读取器先完成密码认证，再检查文件名、类型、数量与大小，最后检查内容校验值。拒绝路径穿越、绝对路径、Windows 设备名、替代数据流、大小写重复路径、符号链接、缺失或额外条目、未知格式版本和重复 JSON 字段。

备份只在目标目录写入加密临时文件，刷新文件内容后以不覆盖的方式发布。取消发生在发布前时不保留目标文件。发布动作开始之后的完成结果优先于较晚到达的取消请求。

设备指纹是硬件 UUID 的加域 SHA-256；UUID 无效时尝试系统 MachineGuid。它用于减少误操作，不是证明硬件身份或许可证真实性的安全凭证。MachineGuid 在重装后可能改变。归档不保存原始硬件 UUID。

许可文件的归档与 Windows 许可数据库的可恢复性是不同问题：本格式确保所读取字节的保存与校验，但不保证运行中数据库的事务一致性，也不提供对系统许可存储的直接写回。
